# Fantasy Author C — Design Provenance

This is an audit document. It is not loaded into a drafting prompt.

## Why this profile exists

Fantasy Author A is a deliberate four-tradition blend (`../../research/salvatore-combat.md`,
`../../research/sanderson-craft.md`, `../../research/ironprince-progression.md`,
`../../research/hwfwm-litrpg.md`). Fantasy Author C is the single-lineage
counterpart, requested specifically so one seat's instincts are not an
average of several traditions: it draws on exactly one clean-room brief and
no other.

## Source of record

- `../../research/ironprince-progression.md` — and only this brief.

No other research file in this repository was folded into this profile's
`VOICE.md` or into `../../craft/modules/tournament-arc.md`. Fantasy Author A's
briefs (Salvatore, Sanderson, HWFWM) were deliberately excluded so this seat's
mechanisms trace to a single documented lineage rather than a blend.

## What the source brief is, and is not

`ironprince-progression.md` states its own method on its first page: it was
compiled from public secondary material only — reviews, craft essays,
wiki/trope compendiums, and one author Q&A — about a specific published
progression-fantasy series. **The novels themselves were not ingested; no
passage was read or reproduced**, and any claim in the brief that is the
researcher's synthesis rather than a source's explicit statement is labeled
`INFERRED`. That constraint is inherited here unchanged.

Because the brief is secondary-source-only, it documents **mechanisms and
architecture** (underdog baseline, coarse-then-fine rank scale, rival-as-clock
pacing, sparring-ladder-into-tournament structure, gear-growth tied to
combat cost, and a documented pacing failure mode around setback density) —
not verbatim sentences, dialogue, character names, place names, or any other
protected expression, because none of that was ever in the source material
available to the research pass. `VOICE.md` and `tournament-arc.md` carry
forward only the mechanisms, in this profile's own words.

## What's in the compiled prompt, and what stays in this file

- No living author is named in `VOICE.md`, in `tournament-arc.md`, in the
  manifest, or in any compiled prompt. The name stays in this file only, as
  an audit trail — matching Fantasy Author A's existing pattern.
- The "Voice register" section of `VOICE.md` turns the source brief's own
  reviewer characterizations of the lineage's prose texture (procedural,
  technical-diction-heavy, clinical during action — §3 and §7) into direct
  register instruction, in this profile's own words. It also carries
  forward the "exhaustive description" pacing failure those same reviews
  flagged, as a pattern to avoid.
- No title, book name, character name, place name, faction name, or
  invented term from the source series appears anywhere in this profile's
  runtime files.

This is the same scope every clean-room brief in this repository ever had:
a brief built from reviews and craft essays has no verbatim sentence to
imitate in the first place, only documented mechanisms and the register
those mechanisms produce. Naming those mechanisms precisely and writing the
register guidance directly — rather than hedging it — is what lets this
seat actually hit the word-choice and sentence-level precision the profile
is for.
