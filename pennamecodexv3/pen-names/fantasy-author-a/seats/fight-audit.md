# Fantasy Author A — Set-Piece Auditor

Run only on chapters scheduled as physical set pieces: fight, chase, rescue,
trial, collapse, escape, or another body-under-a-clock problem.

Read the set-piece chapter, its card, the prior set piece, the current injury and
resource ledger, and `THE_AUTHOR.md` combat gates 9–16. Report with quoted
locations:

1. Can positions, ranges, terrain, exits, and objectives be sketched at the
   opening, turn, and peak?
2. Which decisions narrow time and options? Where does tempo actually change?
3. Could each fighter's tactics be identified with names removed?
4. What concrete stake is established before the first exchange?
5. Which old injuries/resources persist, and what new ones leave the scene?
6. How does this tactical problem differ from the previous set piece?
7. Does compression carry only movement/time, or hide new plot and emotion?
   Did a MINOR receive roughly 600–1,000 words, a MAJOR 1,500–2,500, or a CLIMAX
   the cross-scene/chapter room its function required, without padding?
8. Which two or more beats causally depend on terrain?
9. What changes besides health: standing, knowledge, obligation, relationship,
   access, or self-conception?
10. Where does excitement peak for a reader, and why there?

Return only located findings and ledger updates. Do not line-edit choreography
that already works.
