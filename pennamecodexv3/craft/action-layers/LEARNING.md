# Action layer — Learning

Use when the fight's primary payoff is progression.

- Name the viewpoint fighter's present limitation through action, not a lecture.
- Let the fighter form a usable model, test it, receive contrary evidence, and
  update. The first theory need not be correct.
- Show one correction becoming behavior during the scene. Improvement may reduce a
  loss rather than produce a win.
- A defeat purchases information, technique, changed confidence, or a future plan.
- Let an opponent, observer, or later action make the change externally legible.
- End with a remaining limit. A learning fight opens the next rung.
