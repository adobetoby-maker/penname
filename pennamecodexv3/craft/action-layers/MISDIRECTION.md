# Action layer — Misdirection

Use for a feint, false tell, concealed capability, or tactical trap.

- Plant the signal before exploiting it.
- Give the viewpoint fighter a rational reason to believe the false model.
- Make the deceiver spend position, time, exposure, a resource, or discovery risk.
- Let the false model cause a concrete decision.
- Reveal the trick through physical consequence before explaining it.
- On reread, both interpretations should be possible before the reveal and the true
  interpretation cleaner afterward.
