# Monroe Jackson 1.2.0 — Action stack selector

`CORE` always applies. Select the smallest stack that describes the dramatic
movement already present in the scene card.

| Stack ID | Layers | Use |
|---|---|---|
| `clean` | Core | Short or straightforward action whose purpose is carried by the chapter |
| `learning` | Core + Learning | Durable payoff is a changed model, technique, or limitation |
| `learning-deception` | Core + Learning + Misdirection + Kinetic | A fair false model causes a physical mistake and specific correction |
| `arsenal-climax` | Core + Kinetic + Arsenal + High Stakes | Multiple tools and/or companion serve distinct jobs under irreversible pressure |
| `tactical-climax-learning` | All six | A climax genuinely contains a fair deception, behavioral correction, arsenal, and value choice in one causal chain |
| `power-reveal` | Core + Iron Prince Expansion | A power is called, discovered, or changed outside combat — no fight, but the reader needs to see the mechanism |
| `learning-power` | Core + Learning + Iron Prince Expansion | A practice or fight scene whose payoff is a progression moment in how a power visibly works, not just tactics |

`IRON_PRINCE_EXPANSION` (see `IRON_PRINCE_EXPANSION.md`) is a detail layer, not a
combat layer — compose it with any stack, including ones not listed here, whenever
the scene is a first or early use of a power, or any new power or change to one,
until the reader has been shown the mechanism enough times that restating it would
be inert repetition.

The action bakeoff favored `learning-deception` for the learning fight (8.769) and
`tactical-climax-learning` for the complex climax (9.077), with `arsenal-climax`
the safer climax default (8.885). `MISDIRECTION` alone and `ARSENAL` alone performed
worse than their controls. Do not add a layer merely to make a fight feel larger.

## Four-question action review

1. Can the reader draw the decisive movement and account for active resources?
2. Does each reversal follow from a choice, constraint, or planted fact?
3. Does each special tool solve a distinct problem and carry a cost?
4. What permanently changes in knowledge, body, equipment, trust, or obligation?

If one answer fails, repair that location. If several fail, return one short
diagnosis to the author. Adding more layers is not a repair.
